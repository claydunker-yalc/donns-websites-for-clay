# Donn's websites for Clay

A static GitHub Pages repository for publishing research-result websites that Donn creates for Clay.

## Purpose

When Clay asks Donn to spin up research subagents on a topic, Donn can turn the synthesized results into a static HTML page and publish it here so Clay has a clean web page to review.

## Publishing pattern

- Put standalone research pages under `research/`.
- Keep public pages free of private operational context, secrets, credentials, and sensitive personal details.
- Use relative links so pages work on GitHub Pages.
- Commit and push to `main`; GitHub Pages serves the site from the root of the branch.
